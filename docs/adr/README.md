# Architecture decision records

Architecture decision records capture choices that affect security, operations, or future changes. They explain why the project chose an approach, not only what the current code does.

- [ADR 0001: Shared-schema, row-scoped multi-tenancy](0001-shared-schema-multitenancy.md)
- [ADR 0002: Short-lived access tokens with rotating refresh-token cookies](0002-refresh-token-rotation.md)

New decisions should use the next number and include status, context, decision, consequences, required controls, and a clear condition for revisiting the choice.
